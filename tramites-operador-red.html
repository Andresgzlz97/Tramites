Trámites Operador de RedSeguimiento de expedientes y conexiones

Bienvenido

Inicia sesión con tu cuenta de Gmail. Google te pedirá permiso para guardar tus proyectos en tu Drive y para ver (no modificar) tus correos, y así agruparlos por proyecto.

Configuración inicial (una sola vez)
  1. Entra a console.cloud.google.com y crea un proyecto (ej. "Tramites OR").
  2. En APIs y servicios → Biblioteca, habilita Google Sheets API, Google Drive API y Gmail API.
  3. En Pantalla de consentimiento OAuth, elige "Externo", llena nombre y correo, y agrega tu Gmail como usuario de prueba.
  4. En Credenciales → Crear credenciales → ID de cliente OAuth, tipo Aplicación web. En "Orígenes de JavaScript autorizados" pon la dirección donde abrirás esta página (ej. https://tu-app.vercel.app o http://localhost:8000).
  5. Copia el ID de cliente (termina en .apps.googleusercontent.com) y pégalo con el botón ⚙ de arriba.

Importante: Google no permite iniciar sesión si abres el archivo con doble clic. Ábrelo desde una dirección web (Vercel) o en tu PC con python -m http.server 8000 en la carpeta del archivo y luego http://localhost:8000/tramites-operador-red.html.
